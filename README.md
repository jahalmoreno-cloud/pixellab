# PixelLab — Laboratorio Creativo

## Descripción
PixelLab es un sitio web académico con una identidad visual oscura y detalles verde neón. Presenta ideas de proyectos y explica brevemente cómo se relacionan HTML, CSS, Git y la documentación.

## Archivos del proyecto
- `index.html`: página principal.
- `estilos.css`: estilos compartidos por todas las páginas.
- `pagina1.html`: banco de ideas para proyectos.
- `pagina2.html`: explicación del proceso de desarrollo.
- `README.md`: documentación del proyecto.

## Cómo ejecutarlo
1. Abre la carpeta en Visual Studio Code.
2. Abre `index.html` en un navegador. También puedes usar Live Server.

## Configurar Git
Cambia los valores de ejemplo por tu nombre y correo:

```bash
git config --global user.name "Tu Nombre"
git config --global user.email "tu-correo@ejemplo.com"
```

## Guardar el proyecto en Git

```bash
git init
git status
git add .
git commit -m "Crear sitio inicial PixelLab"
```

## Tecnologías
HTML5, CSS3 y Git.
